# **Friday the 13th Hackathon**

*Theme:* Real-time water quality sensors on Choate Pond, right behind Kessel. A reading every few minutes, 24 hours a day, all year. **The data only matters if a normal person can understand it. That's your job today.**

*Data:*
- What's in the files: Timestamp, Water temperature, pH, Dissolved oxygen, Turbidity, Conductivity, plus a few more, see the repo README. Tip: resample to hourly, normalize to 0 to 1, first 30 minutes.

- Where to get it: CSV flat files, every reading to date. Repo link in the Discord. API for live information as well.

*Challenge:* Make this data mean something to someone who will never read a chart. Rules: real data only  ·  it has to run live  ·  any language, any tools

**Option A: Sonification**

*Turn the readings into sound: music, drums, a soundscape.*
